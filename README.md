# Movie Tracker Platform

Full-stack movie tracking application built as a learning project.

The goal of this project is to build a production-style web application step-by-step while further expanding my knowledge in backend and frontend technologies.

## Tech Stack

Backend

- Node.js
- Express

Database

- PostgreSQL

Frontend (planned)

- React

External APIs

- TMDB API

## Features (Planned)

- User authentication
- Movie search
- Movie details page
- Personal watchlist
- Movie ratings
- User dashboard

## Learning Goals

This project focuses on understanding:

- REST APIs
- Backend architecture
- Database design
- Authentication systems
- Full-stack development workflow

## Development Process

This project is built incrementally with consistent commits to document the learning process and development progress.
